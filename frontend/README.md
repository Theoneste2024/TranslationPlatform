# Translation Platform

A Flutter mobile application for multilingual translation.

## Features

- Text Translation
- Speech Translation
- Driver Mode
- Camera Translation
- Offline Translation (Pack)
- Education Tools
- Google Maps

## Technologies Used

- Flutter
- Dart
- REST API

## Installation

```powershell
git clone https://github.com/Theoneste2024/TranslationPlatform.git
cd TranslationPlatform
cd frontend
flutter pub get
flutter run
```

The authentication API uses the browser host on Flutter web, `10.0.2.2` on the
Android emulator, and `127.0.0.1` on other platforms, with port `8000`. Override
this default when needed (for example, for a physical device or deployed
backend) with `--dart-define=API_BASE_URL=https://api.example.com`.
