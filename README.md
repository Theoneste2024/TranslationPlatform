# Translation Platform

A Flutter mobile application for multilingual translation.

## Features

- Text Translation
- Speech Translation
- Driver Mode
- Camera Translation
- Offline Translation (Pack)
- Education Tools
- Google Maps

## Technologies Used

- Flutter
- Dart
- REST API
